about volos

hardware should feel
like software

volos started with a simple frustration: physical computing was stuck in the 90s. Breadboards, jumper wires, driver installs. We built the deck to make hardware as instant as a print statement.

our story

the timeline

2024

the garage prototype

Three engineers, one soldering iron, and a magnetic connector that refused to stay put. The first deck worked — barely.

2025

first 100 decks shipped

A small crowdfunding run sold out in 48 hours. Every backer got a handwritten note and a free extra module.

2026

8,000 builders and counting

volos is in classrooms, maker spaces and home workshops across 40 countries. The library is fully open source.

what we believe

our values

instant by default

Every design decision starts with "how fast can someone go from idea to running?" If it takes setup, it's wrong.

open everything

Our Python library, firmware and hardware reference designs are open source. You own your tools.

built to last

No planned obsolescence. Modules are repairable, firmware is updatable, and the deck works with every module we've ever made.

getting started

from unboxing to your first blink in four steps.

1

plug in the deck

Connect the volos base deck to any USB-C port. The status LED glows solid blue when ready.

2

install the library

Run pip install volos — that's the entire setup. No drivers, no SDK, no path variables.

3

snap in a module

Push any module into a slot. It registers itself in your namespace the moment it clicks.

4

run your first script

Copy the example below and hit run. Real hardware, real output, zero delay.

hello.py
import volos v = volos.connect() v.display.write("hello, world")
